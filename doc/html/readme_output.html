🌐 1. Web interface with Google Chrome browser (DMS file format) 💬

Upon completion of the run, the controller rank merges the per-rank Chrome traces into <chromevizfilename>.dms. The prefix comes from chromevizfilename in config.cfg (the shipped file uses DisCosTiC). The .dms file is a Chrome trace JSON document. Load it in Google Chrome with:

chrome://tracing

📊 2. Graphical user interface with Vampir (OTF2 file format) 💬

make otf2 runs python visualization/chrome2otf2.py -i DisCosTiC.dms -o DisCosTiC -c. That writes an OTF2 archive in the DisCosTiC directory (DisCosTiC/traces.otf2). Open a small trace in Vampir with:

vampir DisCosTiC/traces.otf2

📊 3. Graphical user interface with ITAC (STF file format) 💬

Two different ITAC products exist.

The modeled application is traced inside the simulator when USE_ITACVIZ is enabled. Rank files are merged to DisCosTiC.avt. make stf runs visualization/convert_itac_stf.sh on that file and writes DisCosTiC.single.stf.

Separately, make trace_MPI or make trace_all rebuilds the simulator with Intel -trace so ITAC can record the simulator process itself. There is no separate launch script for that trace. Open the resulting STF file in Intel Trace Analyzer.
